# COVID-19 Data Exploration Project  

This project explores global **COVID-19 data** using **SQL for data cleaning, transformation, and analysis** and **Tableau for interactive visualization and storytelling**.  
The goal was to practice **real-world data exploration** while answering meaningful business and policy-related questions through clear, data-driven insights.  

---

## Project Overview  

As a data analyst, my objective was to take a large, complex dataset (COVID case and vaccination data) and turn it into **actionable insights**.  
The compiled data focuses on high-level trends and recommendations.  

The core business questions I answered include:  

- **What are the global and regional trends in COVID-19 cases and deaths over time?**  
- **How do vaccination rates differ across countries and continents?**  
- **Which countries show the strongest correlation between vaccinations and case reductions?**  
- **Where should public health organizations focus resources to reduce future outbreaks?**  

---

## Key Insights  

1. **Case & Death Trends**  
   - Countries experienced multiple peaks that aligned with global waves of the pandemic.  
   - Developing countries showed delayed peaks compared to early-hit regions like Europe and North America.  

2. **Vaccination Progress**  
   - Wealthier nations achieved faster vaccination rollouts, while lower-income nations lagged significantly.  
   - Some countries with strong vaccination efforts also showed sharp decreases in hospitalization and death rates.  

3. **Recommendations**  
   - Focus global aid and vaccine distribution in countries with low vaccination rates but rising case numbers.  
   - Continue monitoring breakthrough cases in highly vaccinated populations to improve vaccine effectiveness strategies.  
   - Strengthen data collection and reporting in underrepresented regions for more accurate forecasting.

## Tableau Dashboard  

I designed an **interactive Tableau dashboard** following industry best practices for data visualization.  
The dashboard highlights:  

- Global and country-level COVID-19 case and death trends  
- Vaccination progress by country and continent  
- Comparisons between case counts, deaths, and vaccination rollout  
- User-friendly filters to explore specific regions and timelines
